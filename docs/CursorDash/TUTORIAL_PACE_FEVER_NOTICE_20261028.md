## 1. 일반 처치 회로 — 기존 강렬한 공간 전파 복원

`CursorDashCircuits.ScoreHit`에서 일반 처치만 `ordinaryReactions.Hit`의 최근접 .11/잔향.19/강조배율.58로 보내던 D-061 분기를 제거했다. 이제 일반/피버 모두 **실제 처치 지점의 기존 HitRadial**로 전파한다. 강조.44/전달2.6/폭.32/동시4는 기존 강한 기준 그대로다. 새 반응을 겹쳐 두 배로 하지 않고, 피격 붉은 우선권·숫자 획 가림·이미 걷힌 경로 가시길이와 평상시 흐름을 보존한다. 옛 ordinary 설정3개는 직렬화 호환용으로 숨겨 두며 현재 처치 제어값이 아니다.

## 2. 고스트 연속 곡선 이동과 느린 실습 공급

- 고스트는 목표 없음/반환탄 대기 때 입력을0으로 멈추던 동작을 곡선 순항으로 교체했다. 이동 목표를 완만하게 보간하고, 원형에는 휘어 접근해 실제 접촉한다. 육각은 실제 발사 타이밍에 맞춰 요격 위치 주변의 작은 곡선에서 실제 잔상을 가로지른다. 처치 뒤 .18초 정지 구간을 제거했다. 실제 Controller의 속도·회전·잔상 수명·판정/레이저 시간은 바꾸지 않았다.
- 실제 실습은 **한 개만** 유지한다. 최초 원형 → 육각 → 원형 → 육각이며 실패도 다음 실제 공급 종류를 번갈아 진행한다. 이미2/2가 된 종류는 완료되지 않은 종류로 넘겨 불필요한 실습을 반복하지 않는다. 성공 집계는 원래 실제2+2·동일 실행1회/고스트 분리를 유지한다.
- 생성 시각 기준 반복이 아닌 **실제 처치·실패 회수로 사라진 뒤 1.2초 간격**이다. 살아 있는 동안 다음 공급 시각을 잡지 않는다. 안전한 자리가 없으면 .3초 뒤 다시 후보를 찾고 기존 노드를 지우지 않는다. 양쪽 객체/두 머리/넥서스/HUD/체크리스트/여백 검사 유지.
- 고스트 독립 공급은 2.1→3.1초/상한2, 실제 실습 상한3→1이다. 두 쪽을 한 쌍으로 생성하거나 이동 구역을 나누지 않는다.

## 3. 튜토리얼 실패 피격 — 체력 보호와 실제 화면 반응 분리

기존 protectedHp 경로는 HP를 보존했지만 `confirmedDamage=false`로 예전 약한 공통 반응만 호출했다. Guided 실습의 실제 넥서스 접촉에서 기존 `NexusVisualHit`·`ConfirmedNexusDamage`를 호출해 **본체/원호·붉은 공간 굴절/RGB·붉은 회로·동일 접촉 파편**을 재사용한다. HP setter/실제 Damaged 이벤트/사망은 호출하지 않는다.

`protectedContact` 표시를 별도로 남겨 실제 HP 감소가 있었다고 가장하지 않는다. 해당 이벤트에서는 구형 일반 흰 플래시/별도 국소 굴절을 중복 호출하지 않는다. 고스트 공격 실패는 여전히 화면 반응·실제 피해 없이 로컬 회수되며, 일반 자유훈련의 기존 보호 동작은 변경하지 않는다. 튜토리얼의 충전 손실 표시/배율 초기화·재공급은 기존 경로를 유지한다.

## 5. 첫 피버 안내 — 만충 순간부터 진입과 한 타임라인

기존 다시보기는 `!IsPlaying` 또는 Guided 조건에서 아무 알림 없이 반환했다. 메인·튜토리얼 중 선택하면 기존 빠른 시작 경로로 **기록 제외 정상 검수 라운드**에 들어가 안내를 재생하도록 했다. 튜토리얼을 강제 완료 저장하거나 BEST를 변경하지 않는다. Pause 중 선택은 재개 뒤 재생 예약, 사망/이번점수 대기 중은 메인 복귀 후 선택하라는 메시지를 남긴다. Play가 아니면 Console에 사용법을 표시한다. 기존 넥서스 수동 검수 창에 상태를 읽기 전용으로 표시한다.

정상 첫 만충 때 Closing 전환에서 안내를 예약해 같은 프레임의 처치 정산·효과는 마친 뒤 즉시 덮고, 추가 공격·피해는 차단한다. 기존 ‘진입 완료 후 안내 시작’을 제거했다. 같은 Stage 시간 소유자에서 Pause가 우선하며, 안내는 unscaled 시계로 진행한다.

| 만충 이후 시간 | 패널/게임 시간·공간 표현 |
|---|---|
| 0~3초 | 흰 패널/중앙 검정 정확두줄 alpha1, timeScale0. 링 흡수·위협/공급·8초 소모 없음 |
| 3~5초 | 흰 패널 alpha1→0, 같은 시점부터 SmoothStep 배속 복귀. 기존 Closing→Entering의 링 흡수/응축/에너지 방출·흰 회로 구축이 동기화 |
| 5~6초 | 패널 없음, 배속은 약.741→1로 계속 완화, 공간 구축 마무리 |
| 6초 | 실제 피버 시작: Gauge1/Elapsed0, 기존 공급과8초 진행. 다시보기 완료와 첫 저장의 의미 구분 |

배속은 `SmoothStep((안내경과-3)/3)`이며 4초에 약.259, 5초에 약.741, 6초에1이다. 실제 Closing/Entering 진행은 같은 안내 해제 곡선에 연결하고 실제 피버8초·보너스 공급은 끝까지 보존한다. 종료 순간 기존 회로의 경로별 구축 끝점을 정상 상태로 넘겨 다음 프레임에 회로가 되감기지 않도록 한다. 일반 두 번째 이후 피버의 기존 시간표는 바꾸지 않는다.

4. 메인 또는 Play 중 Tools/최초 피버 안내 다시 보기(기록 보존). 3초 정지→패널2초소멸/배속3초곡선복귀→완전구축·정상피버를 확인한다. 이 경로는 기록 제외다. 실제 최초 안내 자동 발동/저장과는 구분한다.
5. 정지/페이드/복귀 도중 Pause·Retry·Home, 다시 진입 뒤 패널·시간·공급·색·링·점수 상태가 남지 않는지 확인한다.

시각 템포/손 조작·터치·모바일·WebGL·성능은 사용자 검수 대기다. 기존 사용자 작업과 기록을 보존하고 후속 기능을 시작하지 않는다.
