## 4. 사용자 요청 — 노드와 넥서스

### C-01 원형 기본 상태 — USER_REQUEST
현재처럼 게이지가 차는 원형 본체와 회전하는 테두리를 유지한다.

### C-02 원형 공격 — USER_REQUEST
충전 완료 → 회전 테두리가 내부로 빨려들어감 → **전체 원형 본체가 뾰족한 커서 모양으로 변함**
→ 넥서스를 향해 빠르게 돌진 → 피해를 주고 폭발.
기존 원형 레이저는 제거한다. 본체를 남기고 별도 삼각형 탄을 발사하는 방식으로 대체하지 않는다.
흡수·변형이 자연스럽게 연결되어야 한다. 공격 도중 다른 초기 형태가 잠깐 나타나면 안 된다.

### C-03 원형 사망 — USER_REQUEST / OPEN
충전 중 플레이어가 제거하면 지금처럼 원이 부서지는 폭발 느낌을 유지한다.
돌진 형태의 넥서스 충돌 폭발은 요청되어 있으나 구체적인 파편 형태는 미정이다.
현재 공격 형태에 맞는 커서 파편을 사용하자는 것은 PROPOSAL이다.

### H-01 육각 기본 상태 — USER_REQUEST
현재처럼 게이지가 차는 육각형 본체와 테두리를 유지한다.

### H-02 육각 공격 — USER_REQUEST
충전 완료 → 테두리 내부 흡수 → 육각 본체가 **정삼각형**으로 변함 → 레이저 발사.
원형과 달리 노드 본체가 넥서스로 돌진하지 않는다.
반사된 레이저가 돌아와 삼각형을 타격한 뒤 삼각형이 쪼개지며 터진다.

### H-03 레이저 반환 — USER_REQUEST / OPEN
현재의 “막힌 위치에서 새로운 선이 다시 뻗는 모습”을 없애고,
**이미 발사된 레이저가 방향을 바꿔 돌아오는 모습**으로 표현한다.
정확한 빔 길이·모양·속도·반환 방식은 OPEN이다.
길이가 있는 이동 빔은 PROPOSAL이지 승인된 최종 사양이 아니다.
반사 시점과 노드 도달 시점을 분리하고 실제 반환 도착 전에 파괴하지 않는다.

### COMMON-01 테두리 — USER_REQUEST
두 노드 모두 공격 형태가 되었을 때 장식 테두리가 전부 내부로 흡수되어야 한다.
풀에서 다시 등장하면 원래 도형·테두리·게이지 상태로 완전히 복원한다.

### N-01 넥서스 피격 — USER_REQUEST
레이저가 넥서스 중앙까지 들어간 뒤가 아니라 **넥서스 원의 가장자리**에 닿을 때 피해가 발생한다.
원형 돌진도 같은 가장자리 기준을 사용하자는 것은 일관성을 위한 PROPOSAL이다.
빛 번짐이 아닌 단단한 본체 외곽을 판정 기준으로 삼는 것도 PROPOSAL이며 구현 전 확인한다.
피격 경계가 바뀌면 도달 시간이 달라지므로 자동으로 기존 난이도와 같다고 가정하지 않는다.

### N-02 체력 표현 — USER_REQUEST / PROPOSAL
넥서스 내부가 에너지 액체로 차 있는 느낌이며 피해를 받을 때 자연스럽게 줄어들게 한다.
권장 기술 설계: 논리 체력·사망 판정은 즉시, 표시 수위만 부드럽게 최신 값으로 이동.
실제 유체 시뮬레이션은 요구하지 않았다. 마스크·파형·셰이더는 검토 가능한 수단이다.
연속 피해 때 이전 애니메이션이 최신 체력 표시를 덮어쓰지 않게 한다.
