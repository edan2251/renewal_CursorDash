## 2. 배경 속 총점과 반응

기존 `FeverScoreHud.cs`에 작은 소유 표시 클래스 `FeverBackgroundScore`를 추가했다. 새 관리 컴포넌트/Canvas/패널/장식/아트 파일은 없다. 기존 CursorDashFever가 만들고 갱신·해제한다.

- **TextMeshPro 3D** 숫자만 표시. 기존 이사만루 Bold와 그 글꼴의 실제 아틀라스를 사용하는 전용 재질을 복사해 쓴다. 원본 글꼴/공유 재질은 수정하지 않고 글로우·외곽선 없이 선명한 SDF 윤곽을 유지한다.
- 위치는 게임 카메라 뷰포트(.5,.58), 높이는 짧은 화면축42%를 기준으로 한다. 최대 폭80%·최대 확대1.22배와 위치의 화면 여백을 **미리 확보해** 자릿수가 길면 기본 크기를 줄인다. 실제 TMP 치수/GPU 결과는 사용자 검수 대상이다.
- 기존 컬러 배경(-1000) 위/전투 요소 아래의 sortingOrder **-900**. 회로 합성과 넥서스·커서·HUD의 기존 후속 경로는 바꾸지 않는다. 상단 점수·배율은 유지한다.
- 일반 모드 색은 청록(.36,.76,.84), 기본 알파 .105. 피버에서는 기존 흰 세계의 실제 렌더러 알파 마스크에 들어가 낮은 대비 회색으로 보이도록 연결한다. 전환 경계에 따라 픽셀별로 복원하므로 숫자 전체의 색을 갑자기 교체하지 않는다. 피버의 노드/커서/승인 파편 크기·강도·분포는 바꾸지 않았다.
- 실제 `FeverState.Kill`의 중복 방지/기존 점수 더하기 뒤 `PointsAwarded(실제획득량, 정확한총점)` 통지만 추가했다. 이벤트마다 정확한 BigInteger 문자열을 즉시 표시한다. 별도 점수 계산·보상·저장·배율 정책은 없다. Reset/피격 초기화·중복 처치·사망은 가짜 획득 이벤트를 내지 않는다.
- 하나의 감쇠 탄성 상태를 유지한다. 획득 때마다 애니메이션을 재생성/초기화하거나 누적 scale을 곱하지 않는다. 점수는 매 이벤트 바뀌고, 시각 반응만 제한된 상태로 이어진다.
- 반응량 공식은 **이번 게임의 구현 선택**: `w=min(1,ln(1+실제획득량)/ln5)`, 획득량4 이상에서 포화한다. 총점은 공식에 넣지 않는다. 크기 `1+.22×탄성값`/상한1.22, 불투명도 `.105+.14×양의탄성값`/상한.24. 기준 응답 .32초, 작은 한 번의 탄성 여운 뒤 안정한다. 새로운 +점수 팝업/콤보/사운드는 없다.
- fx.enabled를 끄면 탄성 반응은 멈추지만 숫자는 정확히 갱신된다. 밝기 반응은 기존 OnFlash/user.flash도 존중한다. Pause에서 반응 정지, 비활성화/Retry/Home/사망에서 소유 상태·재질·구독을 정리한다.

## 6. 사용자 검수 순서

사용자가 `Assets/Scenes/00.StartScene.unity` → Play → 훈련을 열면 실제 씬은 `Assets/Scenes/Cyberpunk.unity`다. 도구는 `Tools → CursorDash → 넥서스 수동 검수`를 사용한다. 접촉 위치 진단이 켜져 있으면 왜곡/RGB를 의도적으로 우회하므로 시각 검수에서는 끈다.

1. **자연 종료**: 실제8초를 관찰한다. 게이지0 뒤 링만 먼저 나타나고 .20초 동안 노드·흰 화면이 움직이지 않는지, 다음 가속부터 함께 당겨지는지 본다. 초중반 덩어리/타원 이동→링 근처 축소인지 확인한다.
2. **0/소수/상한**: 0개는 Pause 상태에서 기존 ‘만충’/‘현재 단계 끝까지’로 Entering→Fever→Exiting까지 공급 업데이트 없이 진행한 뒤 Resume. 소수는 실제 Fever에서2~3개일 때 Pause→단계 끝→Resume. 상한은 가만히 있어14개에 도달한 뒤 같은 절차(화면 안전공간 때문에 적으면 실제 개수 기록). 내부 시계 재현은 자연8초 검사와 구분한다.
3. **마지막 순간**: 마지막 공간·노드 흡수와 링 수축·광학 정점이 연결되고, 컬러 복귀 뒤에도 수축이 잠깐 보이는지. 다음1배/평상 회전·색수차/흔들림·마스크0을 확인한다. 회수 중 실제 커서를 노드에 겹쳐도 점수/파괴 파편이 늘면 실패다. ‘모델 처치 +1’은 보상을 직접 호출하는 내부 버튼이므로 이 무보상 검사에는 사용하지 않는다.
4. **점수 비교**: 상단 총점과 배경 숫자가 매 획득마다 같은지. 단발/피버 연속/×2~×4의 실제 더 큰 획득에서 반응을 비교한다. 총점이 커져도 같은 획득량의 반응이 계속 커지지 않아야 한다. 현재 라운드 토글로 배경 점수만 꺼도 상단 숫자/배율·입력은 그대로여야 한다. 긴 점수의 실제 글자 치수/극단 자릿수는 아직 미검수다.
5. **화면비/색/레이어**: 세로·긴 모바일 비율·가로에서 숫자 폭/대비/잘림, 배경 위·노드/넥서스/커서 아래 순서를 확인한다. 피버에서 회색 숫자·상단 HUD가 읽히고 종료 후 정상 색/폰트가 복원돼야 한다. 실제 휴대폰 검수는 별도다.
6. **중단**: A/B/C 각각 Pause→Resume, 별도 라운드에서 Retry/Home/검수창0%로 전환. 회수 복사본/마스크·색수차/링 가속/배경 점수 탄성이 남지 않는지, 새 라운드의 정확한0점·기본 표시·입력/시간을 확인한다. 훈련/내부 버튼 검수는 기존대로 최고 기록 대상에서 제외하며 기존 기록을 지우지 않는다.
