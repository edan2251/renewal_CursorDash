## 구현과 기존 동작 연결

- 기본10개 비대칭 경로 묶음/62선/72점/9단자, 밀도 상한12묶음/67선/79점. 처음4묶음부터 상하좌우의 시작점을 갖는다. 길고 짧은 트렁크·분기·평행선이 섞이며 넥서스 바로 주변은 비워 둔다. 원본 픽셀 좌표를 기존 전체 화면 늘림에 대응시켜 경로로 옮긴 것이며 PNG를 런타임에 겹쳐 띄우거나 정적 그림으로 대체하지 않는다.
- 굵은 버스/중간 주선/가는 가지의 폭 메타데이터, 각 점의 incident edge/명시적 단자, 묶음별 최장 경로를 저장한다. 그림에서 교차하는 서로 다른 묶음은 정점 인덱스를 공유하지 않으므로 타격이 건너가지 않는다. 실제 분기는 같은 정점을 공유하여 기존 그래프 거리·분기 감쇠를 따른다. 기존 CircuitPulseField 전달 알고리즘은 그대로다.
- 선 조각마다 떨어진 끝 캡을 반복하던 방식 대신 연결된 스트립/제한된 miter 접합(반폭의 최대1.6배), 진행 끝의 바깥 반원 캡을 사용한다. 명시된 단자에만 링+중앙 접점/희미한 받침을 그린다. 실제 선 폭·가지 폭·단자 반경/외곽선은 독립 조절한다. AA는 가장자리만 처리하며 블러/블룸은 추가하지 않는다.
- 국소 타격 밝기를 선 조각 양 끝에서 계산해 부드럽게 연결한다. 구축/후퇴의 실제 진행 끝에는 별도 짧은 강조가 있으며 완료된 정지 회로 전체를 점멸시키지 않는다. 피버는 기존 합성의 알파를 통해 흰 배경 위 회색 회로로 보이고 국소 부분만 잠깐 더 어두워진다. 컬러 네온 피버로 바꾸지 않는다.
- 기존 실제 hit.point/보너스 접촉점, 가장 가까운 선 시드·연결 그래프 거리·분기 .68 감쇠, 최강 반응/동시4(하드8)를 유지한다. 매 타격에 경로/메시/재질을 다시 생성하지 않는다.
- 진입 경계 밀려남→흰 영역 내 선끝 구축, 기존 종료 A의 회로 흡입0/B의 Exit.Suction/Travel·실제 NexusPosition에 따른 곡선 회수→드러난 컬러 쪽 복원은 기존 시계를 사용한다. 흡입 때 선 폭/단자도 공간 수축과 함께 줄어 중심에 굵은 잔선이 남지 않게 한다. 링·검정 노드·흑백 경계·종료 .20/.51/.24초는 수정하지 않는다.
- 마지막 피격의 바깥 후퇴는 새로 길어진 각 묶음의 최장 경로를 기준으로 진행한다. 루트별 시차≤.16초/후퇴≤.44초, 총≤.60초로 기존 .64초 결과 전환을 지연시키지 않는다. 중간 흡입 중 사망하면 기존의 동결→바깥 해제 흐름도 같은 진행값을 사용한다.
- 재사용 메시2개/재질2개/월드 Renderer1개는 유지한다. 새 최대치의 선 스트립+끝캡+단자를 포함해 메시당 정점 상한을 보수적으로2556으로 잡아 기존6000 List 용량 안에 둔다. 사용자 효과/접근성 값은 양쪽 메시를 그릴 때 프레임당 한 번 읽는다. 이 수치는 정적 용량 확인이며 모바일/WebGL 성능 측정은 아니다.

2. 회로 가까운 여러 위치의 단발→연속 타격: 실제 타격 근처 먼저/연결 가지로 감쇠, 다른 묶음은 조용함. 진행 부분·선끝이 읽힌 뒤 기본 대비로 복귀하고 밝기/반응 수가 누적되지 않음. 일반 노드·승인 파편/커서·점수 보존.
3. 자연 만충/피버 진입: 일반 회로 밀려남→흰 경계 안의 회색 회로가 선끝부터 구축. HUD/배경점수·검정 게임 요소와 분리, 컬러 회로가 흰 세계에 새지 않음.
4. 자연 Gauge0 뒤 종료: A 링 등장 중 회로 흡입 없음→B 가속 때 노드·공간과 같은 중심으로 휘어 흡수/컬러 회로 복원. 넥서스 안에 굵은 잔선/단자가 남지 않음. 기존 링 반동·노드 변형/정리 타이밍 유지.
5. 일반/피버·전환 도중 체력0: 선 끝이 바깥으로 후퇴, 새 회수/구축이 시작되지 않음. 기존 최종 파괴·결과창이 지연/변경되지 않음.
6. Pause/Resume→Retry→Home→새 라운드/반복 피버, 세로·긴 모바일 비율·가로: 이전 반응/회수/기하가 남지 않으며 새 프로필 기본으로 복구. 실제 휴대폰의 굵기/명암/프레임은 별도 확인.

다음 한 작업은 사용자 Unity 검수다. 추가 디자인/육각 타이밍·일반 노드 겹침/새 Flash 그림·무관한 사이버 공간 연출은 시작하지 않는다. 수정은 미커밋으로 남긴다.
