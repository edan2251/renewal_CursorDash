# D-037 — 육각 1·3·5회 충전, 6회 종료에 발사

2026-10-26. 최신 사용자 요청을 적용했다. **수정 후 사용자 Unity 검수 대기**이며, 이전 결과의 시각 승인을 추정하지 않는다.

## 동작과 시각

‘한 박자’는 기존 60도 회전 동작이 **끝나는 순간**이다. 두 테두리는 함께 역회전하므로 첫 링 하나를 기준으로 세며 합산하지 않는다.

| 기준 | 동작 | 기본 생성 후 시각 |
|---|---|---|
| 생성 | 충전 0에서 시작 | 0초 |
| 첫 회전 종료 | 1/3 충전 완료 | 0.4초 |
| 세 번째 회전 종료 | 2/3 충전 완료 | 2.0초 |
| 다섯 번째 회전 종료 | 완충 | 3.6초 |
| 5.5회 | 기존 흡수·6꼭짓점 변형 시작 | 4.2초 |
| 여섯 번째 회전 종료 | 레이저 발사·주 반동 | 4.4초 |
| 비행 완료 | 기존 넥서스 접촉/잔상 방어 처리 | 4.46초 |

표는 현재 프리팹의 이동0.4초/정지0.4초, 회전배율1에 대한 **명목 계산**이다. 실제 화면이나 프레임을 측정한 결과가 아니다. 여섯 번째 이동의 **시작인4.0초에는 발사하지 않는다**. 이전 D-036의5.2초 발사보다0.8초 앞당겼다.

기존 마지막 반회전 슬롯을 한 회 앞당겨5.5→6회에 사용한다. 실제 변형0.175초와 예비동작0.025초를 포함해6회 종료에 발사하므로 뒤에 대기가 더 붙지 않는다. 저장된 변형 상한0.25초와 프리팹은 변경하지 않았다. 회전 속도를 바꾸면 기존 방식으로 같은 슬롯에 맞춰 배분한다. 비행0.06초, 반사·피해·반동·에너지 배출은 그대로다.

충전은 1·3·5번째 이동 중에 부드럽게 차고, 종료 때 각각1/3·2/3·완충에 도달한다. 짝수 이동에는 충전량을 유지하며 기존 짧은 탄성만 남긴다. 생성 첫 프레임의 값은0이다.
