# D-036 — 육각 2·4·6회 충전, 6.5회 변형, 7회 발사

2026-10-26 / 최신 사용자 요청. **구현·정적/순수 검사 완료, 사용자 Unity 검수 대기**.

## 바꾼 동작

생성 때0/3으로 등장하고 첫 회전도 비어 있다. 2·4·6번째 이동 중에 각각1/3씩 차며 완료 때 기존의 짧은 탄성으로 안정한다. 다른 이동/정지 구간에는 충전량을 유지한다. 기존60도 이동 동작1회를1회로 세고 두 역회전 테두리를 합산하지 않는다.

| 단계 | 기준 | 기본 생성 후 시각 |
|---|---|---|
| 등장·첫 회전 | 충전0/3 | 0~.4초 및 다음 충전 전 |
| 1/3 충전 완료 | 2회 | 1.2초 |
| 2/3 충전 완료 | 4회 | 2.8초 |
| 완충 | 6회 | 4.4초 |
| 기존 흡수·6꼭짓점 변형 시작 | 6.5회 | 5.0초 |
| 레이저 발사·주 반동 | 7회 완료 | 5.2초 |
| 레이저 넥서스 도달 | 비행.06초 유지 | 5.26초 |

표는프리팹저장값(60도이동.4초/정지.4초/회전배율1)의 **명목계산이며실측아니다**. 이전D-035의발사5.475/도달5.535초보다.275초앞당겼다. 비행속도/반환시간·전체경로잔상방어/피해·점수규칙은변경하지않았다.

6.5회는일곱번째이동의중간이다. 그때부터7회완료까지.20초밖에없으므로기존morph설정.25초를그대로뒤에더하면요청시점에발사할수없다. **실제변형.175초+예비.025초**를이구간에배분했다. 저장된.25는상한으로남겼고프리팹을덮어쓰지않았다. 더짧은morph설정이면변형후완성된모양으로남은시간을기다리고7회에발사한다.

회전배율변경에도마지막반이동안에맞춘다. 예: 배율2이면반이동.10초/변형.075+예비.025,배율.5이면반이동.40초/변형.25+완성형대기.15다. 예비설정이슬롯보다너무길면슬롯절반이하로제한해변형구간을남긴다. 이배분은사용자시각검수대기인구현선택이다.

## 시계와 취소 처리

기존ArrowNode상태흐름을그대로활용한다. Preparing뿐아니라Warning에서도같은실제Rotator tween진행을LateUpdate에서읽는다. 따라서변형완료뒤별도시간을더세어발사가밀리지않는다. 큰프레임으로문턱을넘으면완성형을만든뒤현재진행값으로발사하고추가예약콜백은만들지않는다.

회전시계는7회발사때자기두컴포넌트만중지한다. 흡수표시는시작당시의실제각도를기록해반회전중초기각도로튕기지않게연결했다. 회전컴포넌트자체의속도/정지/방향/트윈코드는이번에바꾸지않았다. 일시정지·피버진입취소·게임오버·Retry/Home·비활성화/풀재사용에서기존정리흐름을유지하고새변형진행값도초기화한다.

첫링이없으면둘째링,두링모두회전없으면기존`hex.prepare`를7회에해당하는발사까지의안전대체시간으로쓴다. 기본회전없음은3.25초변형→3.5초발사다. 사용자설정/저장프리셋은초기화하지않았다.
