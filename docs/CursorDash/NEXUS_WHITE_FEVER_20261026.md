## 사용자 Unity 검수

1. 기존 Play를 종료하고 컴파일 완료/Console의 새 오류부터 확인한다. `Assets/Scenes/01.StageSelectScene.unity`에서 직접 Play→훈련. 기존 타이틀 로고는 같고 숫자는 Bold/안내는 Medium, 최고점수는 정수여야 한다. 게임 씬은 `Assets/Scenes/Cyberpunk.unity`다.
2. `Tools → CursorDash → 넥서스 수동 검수`에서 최대100%/중간50%/낮음15%를 바꾼다. 중앙 ×N이 회전하지 않고 모든 HP에서 읽히며 수위는 평상시 정지/피격 때 즉시 감소해야 한다. 본체 경계/커서 겹침도 함께 본다. 입력/물리 확인은 실제 커서를 움직여 수행한다.
3. 실제 원형 저지/육각 반환 파괴를 몇 번 한다. 기본 .125씩 연속 충전돼 원호 내부도 부드럽게 차고, 원호5개 자체는 회전하지 않아야 한다. 점선만 잠깐 빨라진 뒤 안정돼야 한다. 넥서스 피격 반응은 더 강하고 반복해도 속도가 끝없이 오르면 실패다. 기존 공격/파괴/반사 느낌은 새 배경에서 회귀 확인한다.
4. `만충 → 원호 흡수 준비`를 눌러 한 주기를 본다(내부 검수·기록 제외). 바깥 선행 회전/나선→점선 동반→응축→빠른 흰 확산이어야 한다. 긴 팔/단순 동시축소가 보이면 제보한다. 흰 배경·옅은 회로/검은 주요 요소, HP/중앙 ×N/고정 점수·일시정지를 확인한다.
5. 보너스를 직접 연속 통과한다. 검은 큰 도형·불규칙 파편이 궤적과 구분되고, 검은 넥서스 위 커서는 얇은 흰 가장자리로 보여야 한다. 조작/궤적은 이어지고 흰 전체 점멸·긴 정지가 누적되면 실패다. 검은5원호 시간 표시의 읽힘은 **임시 시안 검수**다. 점선은 유지 중 숨김이다.
6. 끝에서 바깥의 곡선 유입→현재 흐르는 색 복귀→링 복원→배율1회 상승을 본다. 배경/글꼴이 튀거나 멈춘 위치가 리셋되면 실패다. 배경은 일반 상태에서10~20초 정도 지켜보면 큰 색 경계가 은은하게 이동해야 한다. 일반 파괴/피격의 짧은 배경 반응은 그보다 빠르게 읽혀야 한다.
7. 한 번 pause/resume, 별도 회차에서 피버 취소/Retry/Home과 HP0을 확인한다. 색·링·시간·입력이 복구되고 중단으로 배율이 오르지 않아야 한다. 훈련 최고점수는 쓰지 않는다. 실제 최고점수 저장은 필요할 때 일반 모드에서 기존 최고보다 높은 점수로 종료→결과 이번/최고→메인 최고를 비교한다. 기존 생존시간 키를 삭제/초기화하지 않는다.

소스/Inspector 상 연결됐다는 표시나 합성 호출 증가는 화면 품질의 PASS가 아니다. 사용자 검수 후에만 D단계 범위를 정한다.
