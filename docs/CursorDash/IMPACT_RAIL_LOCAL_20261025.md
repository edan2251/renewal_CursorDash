## 1. A — 원형 저지 파괴

호출은 그대로 `PlayerCharacterController → NormalNode.ContactAt/Interaction → StageManager.RegisterCircleSheetContact → HitFeedback.EmitCircle → CircularBreakVfx`다. 이름이 남은 legacy sheet 인수는 재생하지 않는다. C/D와 승인 B의 `ImpactFragments`에는 연결하지 않는다.

- 고정된 두 덩어리(owner -2)를 완전히 제거했다. 서로 다른 삼각형/불규칙 사각형의 개별 파편을 처음부터 표시한다. 프레임마다 난수를 쓰지 않고 발생별 seed로 크기·각도·속도·회전·소멸 시점을 달리한다.
- 원형 파편 기본 **8→12개**, 수명 상한 기본 **.28→.34초**. 각 파편은 이 시간의 .78~1배(.2652~.34초) 살아 있다. 기존 사용자 프리셋은 덮어쓰지 않는다.
- 길이는 본체 반경R의 **.25~.52배**를 기준으로 한다. 기존 크기 입력.05를1배로 삼고 .3~1.25배로 제한한다. 삼각형/사각형의 길이·폭 비율도 서로 다르다.
- 첫 프레임부터 본체보다 넓게 분포하며 전방 **18~80도**의 비대칭 양쪽 펼침을 사용한다. 기본 속도2.4×2.4~4.3 = **5.76~10.32월드/초**, 감속6.5~11.5/s. 본체가 사방으로 균등 확산하거나 가는 한 줄로만 나가지 않는다.
- 수명의48%까지 크기를 유지하고 끝까지 최대32%만 축소한다. 알파는42%까지 유지한 뒤 부드럽게 정리한다. 빠르게 점이 되는 이전 축소(-80%)를 제거했다. 처음 강하고 이후 감속하며, 커서가 통과한 뒤에도 일부 조각이 남도록 했다.
- 진행축의 초기 작은 여백(.15R)과 기존 실제 커서 전경 합성을 유지한다. 이동·입력·충돌·커서 좌표/궤적을 VFX가 변경하지 않는다. 접촉 섬광.035초와 화면 플래시/왜곡은 다른 경로다.
- **화면 반응/히트스톱/셰이크/왜곡·승인 B 수치는 변경하지 않았다.** A의 화면11기본값도 D-026 그대로다. 이번 변경은 파편만이다.

`circle-geometry-model.png`는 수식을 그린 정적 모델이며 Unity 화면이 아니다. 파편 수/정리 타이밍의 최종 만족도는 사용자 검수 대기다.

## 2. 넥서스 최종 — 빠른 첫 분리 후 느린 마무리

기존 `DamageNexusContact → Hp setter → Death`의 1회 처리와 일반 최종 피격 중복 방지, StopGameplay/Retry/Home은 그대로다. 최종 VFX의 시간 함수만 변경했다.

| 구간 | 이전 | 이번 |
|---|---|---|
| 압축 후 본체 분리 | .05초 | **.016초** |
| 첫 분리 시계 | 바로 .25배 | **첫 .05초 동안2.2배** |
| 느린 꼬리 | 첫 .20초 | 빠른 분리 뒤 **.16초·.25배** |
| 이후 정리 | 1.4배 | 1.4배 유지 |
| 결과 표시 대기 | .64초 | **.64초 유지** |

최종 파편 위치·회전·축소·알파 모두 같은 `FinaleMotionAge`를 사용한다. 일반 `timeScale`만 낮추고 실시간 파편을 방치하지 않는다. 전역 timeScale은 새로 건드리지 않는다. .016~.066초에 파편 이동 시계가0→.11초 진행하고, .066~.226초는 느려진다. 60fps에서는 압축이 약1프레임이며 실제 프레임 시각에 따라 양자화된다.

**방향 함수 +incoming, 색·12본체셀+24칩·보조 분산, 접촉 섬광/화면 강도, 결과 흐름은 보존했다.** `InitializeContact`의 C/D 시계·분출 방향/수치도 그대로다. HUD를 파편으로 만들지 않는다. 기존 치명타 단발 가드/Retry·Home의 예약 취소·시간/입력 정리 코드는 바꾸지 않았다. 실제 복구는 사용자 검수 대상이다.

## 3. 육각 — 충전 유지, 발사 순간 반동, 빠른 도달

실제 저장값은 `ArrowNode.prefab`의 준비3.5/변형.25/도달.25였다. Cyberpunk 씬에는 이 시간의 별도 override가 없으며 기존 풀은 이 프리팹 인스턴스를 사용한다. 도달 저장값과 C# 기본값·`hex.attack` 메타 기본값을 **.06초**로 맞췄다. 사용자 세션에서 명시적으로 바꾼 실험값은 강제로 초기화하지 않는다.

| 생성 시점을0으로 한 명목 게임시간 | 이전 | 이번 |
|---|---:|---:|
| 충전 완료 | 3.500 | 3.500 |
| 변형/예고 완료 | 3.750 | 3.750 |

| 실제 발사 | 3.830 | **3.775** |
| 발사→50% 위치 잔상 교차(가정) | .125 | **.030** |
| 해당 교차의 생성 기준 시각 | 3.955 | **3.805** |

이 표는 코드/저장값의 계산값이다. 실제 Unity 실측은 NOT_RUN. 방어 지점이 경로 비율f이면 발사→교차는 기존 .25f, 새 .06f다. 유한 굵기/경계, 프레임 시간, 일시정지·히트스톱·개발 시간배율에 따라 관측 시각이 달라진다. 도달 속도는 같은 거리에서 약4.17배이며, 충전 시간을 줄인 것이 아니다.

주 반동은 예고 중에 미리 당기지 않고 **발사 시작과 같은 프레임**에 시작한다. .08초 안에 반대 방향으로 짧게 밀리고 복귀한다(최대 구간비15%, 약.012초). 기존 반동 거리 비율.08을 유지하며 기본 월드 거리 약.02944다. 논리 원점/콜라이더는 움직이지 않고 표시 자식만 움직인다. 기존 6꼭짓점/방향/충전은 유지한다. 뒤→앞 에너지 배출은 실제 발사부터 새 비행 시간에 맞춰 진행한다.

충돌은 기존 `TryBlockBeam(origin, tip, beamDefenseRadius)`가 **매 갱신 때 원점→현재 끝점 전체**를 검사한다. 빠른 끝점만 점검하지 않는다. 잔상 유효 수명·굵기·가장 먼저 만나는 방어 선택과 반환 규칙은 그대로다. 즉시 전체 경로 판정으로 바꾸지 않았다.

넥서스 도달 전에 잔상 검사를 먼저 하고, 피해는 도달 플래그를 세운 다음1회 호출한다. 이후 .06초의 선은 알파만 사라지는 **시각 전용 꼬리**로, 새 잔상을 반사하거나 피해를 다시 주지 않는다. 꼬리는 게임시계이므로 기존 피격 히트스톱 동안 멈출 수 있다(기본 피격정지.08초를 포함하면 실시간 노출은 약.14초). 수명 연장으로 방어를 쉽게 만들지 않았다.

발사 예약 코루틴/지연 콜백을 만들지 않았다. Reset/OnDisable은 예비동작·반동·도달 플래그·광선/색을 복원한다. 치명타 때 `DamageNexus`가 노드를 즉시 Reset해도 꼬리를 다시 켜지 않는다. 일시정지는 기존 게임시계 조건으로 멈춘다.

수동 검수창 `Tools → CursorDash → 넥서스 수동 검수`에 **변형완료/발사/잔상접촉/넥서스 도달 게임시각**을 읽기 전용으로 추가했다. -1은 이번 실행에서 해당 사건이 아직 없다는 뜻이다. 재사용 Execute 때 초기화한다. 여러 노드가 동시에 있으면 창은 활성 육각 한 개를 표시하므로1개 생성으로 검수한다. 활성 육각이 없어지면 직전에 관찰한 노드의 시각을 유지해 풀 복귀 후에도 읽을 수 있다.

3. **육각 방어 B/속도**: 육각1개만 생성. 기존 충전/6꼭짓점 변형을 보고 경로 앞에 잔상을 남긴다. 짧은 멈칫→발사와 반동→빠른 접촉→기존 .06초 반환→승인 육각 파괴를 확인한다. 가까운/중간/넥서스 근처, 수직/비스듬한 잔상을 각각 시도한다. 창의 발사·접촉 시각 차이를 확인한다. 방어 실패 시 HP가1회만 깎이고, 뒤늦게 만든 잔상이 남은 선을 다시 반사하지 않아야 한다.
4. **취소·시간**: 예비동작 중 노드 정리, 발사 중 일시정지/재개, 재시도·메인 복귀 후 다시 생성한다. 늦은 발사/회전·반동 위치 잔류/중복 피해가 없어야 한다. 기본 잔상 수명은 이전과 같아야 한다.
5. **최종 파괴**: 수동창에서 낮음15%/훈련 무적 해제 후 C 또는 D를 방치한다. 방향 검수는 Play 중 게임판 `NodeCreator`의 기존 Inspector `Normal Node Generate`/`Arrow Node Generate` 버튼으로 노드를 생성한다. 위/아래/왼쪽/오른쪽이 나오도록 정리·재생성해 각각 마지막 타격을 받는다. `0%` 버튼은 실제 마지막 공격 방향 검수용이 아니다. 현재 방향 그대로, 피격 직후 바로 크게 분리→느린 파편→.64초 결과 흐름을 확인한다. 체력0/결과1회, 결과 전/후 Retry·Home 뒤 시간1과 정상 입력을 확인한다.

다음 한 작업은 사용자 로컬 전투/시각 검수다. 추가 수치 조정·빌드·커밋·배포는 별도 요청을 기다린다.
