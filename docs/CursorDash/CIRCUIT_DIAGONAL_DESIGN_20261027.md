## 무엇을 바꿨는가

- 긴 주회로에서 보조선이 대각으로 갈라지는 같은 계열로 다시 그렸다. 원본 PNG의 긴 줄기/안팎의 여백·엇갈린 선 길이는 참고하되, 직각 L/T자·짧은 U자 되돌림/블록형 꺾임을 남기지 않았다.
- 작성 좌표1080×1920에서 수직/수평 구간과45도 대각선으로 구성하고 **진행 방향의 변화는 최대45도**다. 모든 꺾임/분기에는 서로 직교하는 두 다리가 없다. 분기는 실제 공유 정점의 Y자만 사용한다. 가로·세로 선 자체를 금지한 것이 아니라 둘이90도로 직접 만나지 않게 했다.
- 기본10묶음/62선에서 **8묶음/56선/64점**으로 정돈했다. 기본4개의 긴 주회로와4개의 짧은 보조 묶음이며 상하좌우 진입/넥서스 주변 여백을 유지한다. 각 선의 길이와 끝 위치를 엇갈리게 하여 좌우/상하 반복감을 줄였다. 조절 상한12묶음은66선/78점이다.
- 새로운 굵은 원 단자·받침은 추가하지 않았다. 모든 끝은 선 폭에 맞춘 기존 반원 캡, 꺾임은 기존 제한 miter, Y접합은 선 폭의 작은 채움으로 연결한다. 기존 Max 커버리지 합집합을 재사용해 접합 면 중첩으로 농도가 늘어나는 경로도 유지했다. 접합 구현 자체나 셰이더를 바꾸지는 않았다.
- 교차처럼 보이지만 연결되지 않은 경로도 없도록 새 좌표를 작성했다. 실제 연결은 그래프 인덱스로만 결정하며 타격 전달·분기 감쇠/동시상한은 그대로다. 화면비에 따른 기존 뷰포트 늘림을 유지하므로 대각의 화면상 각도는 화면비에 따라 달라질 수 있다. 모든 비율에서 화면상45도라고 주장하지 않는다.

## 사용자 검수 순서와 다음 한 작업

사용자가 `Assets/Scenes/Cyberpunk.unity`에서 직접 Play한다. 기존 `Tools → CursorDash → 넥서스 수동 검수`/프로필을 사용한다.
