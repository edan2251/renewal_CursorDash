- 실제 NormalNode.prefab의 준비2.5초/예고0.25초/기존 도달0.5초를 유지하고 도달 필드를 dashDuration으로 이관한다. 신규 길이1.6/폭1.05(노드 로컬), 충돌 연출0.4초, 보라색(0.68,0.12,1,1)은 Inspector 조정값이다.
- Cyberpunk HpBar는 중심(0,0), Rect211×211, scale0.00520833349다. Inside.png의 불투명 본체 지름 약125px를 채택해 solidFraction=125/211=0.59241706, 임시 월드 반경0.3255208로 쓴다. 빛 번짐은 제외한다. StageManager의 원형 전용 중심/반경 참조를 추가하며 육각 NexusPosition은 변경하지 않는다.
- 커서의 보이는 앞점 이동 구간과 원 경계를 교차 검사하고 피해 가드를 먼저 확정한 뒤 기존 DamageNexus를 호출한다. 빠른 이동 누락·중복 피해를 방지한다.
- 원형 테두리의 변형과 회전 트윈이 충돌하므로 Rotator의 자기 트윈만 OnEnable/OnDisable/OnDestroy에서 관리한다. 육각/HP 공유 사용처는 회귀 검증한다. 전역 KillAll/경고 숨김/Safe Mode 변경은 하지 않는다.

실행 결과와 실제 화면·수동 미확인 범위는 STATUS/VALIDATION의 최신 원형 시안 기록을 따른다.

## 폐기/대체된 제안

- “원형 본체를 남기고 삼각형 탄을 분리 발사”는 이전 제안이며 D-002에 맞지 않는다.
- “모든 리소스를 2D PNG 프레임으로 준비”는 필수 조건이 아니다. 구현 수단은 미정이다.
- 8단계까지 모든 UI를 미루지 않는다. 기능 UI는 기능 단계에서, 전체 디자인 마감은 8단계에서 한다.
