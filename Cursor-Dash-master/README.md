## WebGL

The WebGL build is generated in `Builds/Web` using the enabled scenes in
`ProjectSettings/EditorBuildSettings.asset`. Run the editor methods
`MigrationValidation.Validate` and `MigrationValidation.BuildWeb` in batch mode
to check asset references and create the build. Serve the generated directory
over HTTP with gzip encoding for the compressed `.gz` files.
